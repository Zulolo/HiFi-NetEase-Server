# web/ · Mobile-first PWA

The primary remote control (FR-2) and the upload page (FR-3). Served by `hifid`
from embedded assets; installable on Android/iOS home screens.

No code yet. Planned stack and screens are in docs/06 and docs/07.

Planned screens:

1. Now Playing: cover, title/artist, format badge ("DSD128 native", "PCM 24/96"),
   transport, volume, output selector.
2. NetEase: my playlists, liked songs, daily recommendation, search, cloud disk,
   download button per track/playlist with progress.
3. Library: artists/albums/folders from MPD, recently added (uploads).
4. Queue: reorder, remove, clear, save as playlist.
5. Upload: drag-and-drop files/folders, resumable, per-file progress and hash check.
6. Settings: login (QR), outputs (alias, DSD mode, volume mode), server status page.
